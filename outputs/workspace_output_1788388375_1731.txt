# Security Policy

## Supported Versions

We actively support the latest version of FED‑Badge. Security updates are applied to the `main` branch.

| Version | Supported |
| :--- | :--- |
| Latest (2.x) | ✅ |
| 1.x | ❌ |

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability, please do **not** open a public issue.

Instead, please email us directly at:

📧 **security@fedpromptly.com**

Or use the **"Report a vulnerability"** button on the Security tab of this repository (draft a security advisory).

### What to include
- A clear description of the vulnerability.
- Steps to reproduce it.
- The impact and potential exploit.
- Any suggested fix (optional).

### Response timeline
- We will acknowledge your report within **48 hours**.
- We will work on a fix and aim to release it within **7 days** (depending on severity).
- We will credit you in the release notes unless you prefer to remain anonymous.

Thank you for helping keep FED‑Badge secure!

## Disclosure Policy

We follow responsible disclosure. Once a fix is released, we will publicly disclose the issue in the changelog.

## Contact

For non‑security issues, please use GitHub Discussions or open a regular issue.
