How It Works

FED‑Badge generates badges using multiple services. Fill in the controls and copy the output that works best for you.

Services

  • Shields.io – Full-featured, supports logos, style, label colour, cache, links.
  • Badgen.net – Simple and fast, no extra parameters.
  • Badges.ws – Similar to Badgen, supports style.
  • BadgeWind – Tailwind‑styled badges via API.
  • Raw SVG – Self‑contained SVG, works offline.
  • GitHub Actions – Native workflow status badge (exact URL format).

Usage

1. Enter your label, message, and colours.
2. Choose a style or leave default.
3. Copy the HTML, Markdown, or raw URL from any badge card.
4. Paste into your README or website.

HTML – works in GitHub READMEs, websites.
Markdown – standard [![alt](url)](link) format.
Output – raw badge URL or SVG code.

GitHub Actions Workflow

Enter your repository (e.g., owner/repo) and workflow filename (e.g., ci.yml) to generate the exact badge URL that GitHub renders.
