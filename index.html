📖 Documentation


      

        
How It Works

        
FED‑Badge generates badges using multiple services and includes an ASCII animation studio. Fill in the controls, copy the output that works best for you, or scan a folder for animated ASCII art.

      


      

        
Badge Services

        
    
          
  • Shields.io – Full-featured, supports logos, style, label colour, cache, links.
    • 
          
  • Badgen.net – Simple and fast, no extra parameters.
    • 
          
  • Badges.ws – Similar to Badgen, supports style.
    • 
          
  • BadgeWind – Tailwind‑styled badges via API.
    • 
          
  • Raw SVG – Self-contained SVG, works offline.
    • 
          
  • GitHub Actions – Native workflow status badge (exact URL format).
    • 
        

      


      

        
Badge Usage

        
1. Enter your label, message, and colours.

        2. Choose a style or leave default.

        3. Copy the HTML, Markdown, or raw URL from any badge card.

        4. Paste into your README or website.

        
HTML – works in GitHub READMEs, websites.

        Markdown – standard [![alt](url)](link) format.

        Output – raw badge URL or SVG code.

      


      

        
GitHub Actions Workflow

        
Enter your repository (e.g., owner/repo) and workflow filename (e.g., ci.yml) to generate the exact badge URL that GitHub renders.

      


      

        
FED‑ETCH ASCII Studio

        
    
          
  1. Click Scan Folder and choose any directory (Chrome / Edge use the native picker; Firefox / Safari fall back to a folder upload dialog).
    2. 
          
  2. The studio reads your structure and renders an ASCII tree using box‑drawing characters.
    3. 
          
  3. Press Play to animate the tree as a cascading rain of file names.
    4. 
          
  4. Adjust the Speed slider to taste.
    5. 
          
  5. Use Copy ASCII or Download .txt to export the static tree for your README.
    6. 
          
  6. No folder handy? Demo Mode loads a built‑in mock repository instantly.
    7. 
        

        
Folders whose names begin with a dot (.) are skipped, and scan limits (max files, depth, size) protect your browser from enormous directories.
